# XY 桌面播放器主题模板

复制整个文件夹并改名，然后替换 `pack.json`、`songs.json` 和素材文件。主题文件夹应保持以下结构：

```text
你的主题/
├─ pack.json
├─ songs.json
├─ audio/
├─ images/covers/
└─ lyrics/
```

- `pack.json`：主题 ID、显示名称、作者和默认颜色。
- `songs.json`：每首歌自己的歌名、歌手、歌曲、封面、歌词和固定背景色。
- 所有素材路径都必须使用主题文件夹内的相对路径；不能使用网址、盘符路径或 `..`。
- 当前支持常见音频、图片、LRC 歌词与字体文件；主题不能包含或执行 JavaScript、EXE。
- 完成后把整个主题文件夹复制到托盘菜单“主题 → 打开主题安装目录”所打开的位置，再点“重新扫描主题”。
- 修改当前正在播放的主题后，点托盘菜单“重新加载播放器”才会读取新内容。

模板只提供结构，不附带音乐、封面或歌词。制作和分发主题时，请自行确认素材授权。

# XY 桌面播放器主题骨架设计

日期：2026-09-01
状态：已由用户确认

## 目标

把当前只能运行“孤独摇滚”内容的桌面播放器整理成一个稳定、可复用的播放器骨架。播放器程序只维护界面、播放、桌面嵌入、交互、自动暂停和主题切换；具体音乐、封面、歌词与配色放入独立主题文件夹。

首版继续把“孤独摇滚”作为内置主题和故障回退主题。以后可以修改发布版的默认主题，但内置主题始终存在且不能被用户删除或覆盖。

## 用户安装模型

主题作者发布 ZIP 文件，用户自行解压。程序不直接读取 ZIP、不提供导入对话框，也不负责解压、覆盖更新或版本选择。

用户主题目录为：

```text
%LOCALAPPDATA%\XYDesktopPlayer\Themes
```

目录下每个一级文件夹代表一个主题。复制新文件夹即安装，覆盖复制即更新，删除文件夹即卸载。程序只扫描包含有效 `pack.json` 的一级文件夹，不递归寻找嵌套主题。

新增或删除文件夹后自动刷新托盘主题菜单。覆盖当前主题时不自动重新加载，避免复制尚未完成时读到半套素材；用户完成复制后点击现有的“重新加载播放器”。

## 总体架构

播放器由三层组成：

1. Windows 宿主：窗口/桌面模式、WorkerW 嵌入、托盘菜单、桌面交互、前台程序检测、单实例和异常日志。
2. 共用 Web 播放器：播放控制、播放列表、歌词、时钟、视觉效果和由配置驱动的外观。
3. 主题数据：音乐、封面、歌词、颜色、字体、Logo、图标和装饰图片；不允许包含 JavaScript、EXE 或其他可执行代码。

原 Web 播放器的上游项目是 `OriginalCube/Bocchi-Wallpaper`，采用 MIT 许可证。重构时使用并改造公开源代码，保留许可证、作者声明和第三方通知，不继续直接修改压缩后的 JavaScript。上游许可证不替代对音乐、图片和游戏素材传播权的确认。

## 主题目录格式

```text
无限暖暖/
├─ pack.json
├─ songs.json
├─ images/
│  ├─ logo.png
│  ├─ decorations/
│  └─ covers/
├─ audio/
├─ lyrics/
└─ fonts/
```

`pack.json` 保存主题级信息：格式版本、稳定 ID、显示名称、作者、主题级 Logo、字体、装饰图和默认外观。`songs.json` 保存歌曲列表。

示例 `pack.json`：

```json
{
  "format": 1,
  "id": "infinity-nikki",
  "name": "无限暖暖",
  "author": "作者名称",
  "appearance": {
    "logo": "images/logo.png",
    "accentColor": "#F2B8D5",
    "textColor": "#FFFFFF"
  }
}
```

每首歌拥有独立的歌名、歌手、音频、封面、歌词和固定背景颜色，也可覆盖文字颜色、强调色与歌曲背景图：

```json
[
  {
    "title": "歌曲名",
    "artist": "歌手",
    "audio": "audio/01.mp3",
    "cover": "images/covers/01.webp",
    "backgroundColor": "#D7A0B7",
    "textColor": "#FFFFFF",
    "lyrics": {
      "original": "lyrics/01.lrc",
      "translation": "lyrics/01-zh.lrc"
    }
  }
]
```

歌词、翻译歌词、主题字体、Logo 和装饰图可以省略。计划支持 MP3、M4A、FLAC、WAV、OGG，以及 PNG、JPG、WebP、GIF；最终以 WebView2 实际播放测试结果为准。

所有路径必须是相对于主题根目录的安全相对路径，解析后的文件必须仍位于该主题文件夹内。主题 ID 不参与版本判断；重复 ID 视为冲突，不能覆盖保留的内置主题 ID。

## 扫描、选择与回退

启动流程：

1. 注册内置“孤独摇滚”主题。
2. 扫描用户主题目录的一级子文件夹并验证配置。
3. 读取用户上次选择；不存在、损坏或没有可播放歌曲时退回内置主题。
4. 没有用户选择时使用发布配置中的 `defaultThemeId`，首版为内置主题。

切换主题时保留窗口/桌面模式、桌面交互以及手动暂停状态，新主题从第一首歌开始。如果当前处于因其他前台程序造成的自动暂停状态，则等待回到桌面后再开始播放。

删除当前用户主题时自动退回内置主题。个别歌曲素材损坏时跳过该歌曲；整个主题配置损坏或没有有效歌曲时忽略该主题并记录日志，不让程序崩溃。

## 托盘菜单

```text
切换-窗口模式
切换-桌面模式
桌面交互
主题 >
    ✓ 孤独摇滚
      无限暖暖
      绝区零
    ──────────
    打开主题目录
    重新扫描主题
重新加载播放器
退出
```

模式、桌面交互和当前主题使用勾选状态表示。打开主题目录只打开 `%LOCALAPPDATA%\XYDesktopPlayer\Themes`，不做安装操作。

## 播放与状态规则

- 每次启动程序都直接播放；如果已有其他程序位于桌面上方，则等回到桌面后开始。
- 用户手动暂停不会被自动恢复。
- 桌面上方出现其他正常程序窗口时自动暂停，音量约 500 毫秒淡出至静音。
- 回到桌面后立即继续播放，不做淡入延迟。
- 重新加载播放器保留宿主模式、桌面交互和手动暂停状态。
- 自动暂停与手动暂停使用不同状态，不相互覆盖。

手动暂停只在当前程序进程内保留，不跨退出和重新启动保存。这与“打开程序后直接开始播放”的既有要求一致。

## 稳定性与安全

- 使用单实例保护，重复启动不创建第二个播放器。
- 注册 UI 线程和非 UI 线程的全局异常处理，将日志写入用户本地数据目录。
- 主题不能执行脚本，不能引用网络资源或主题目录外文件。
- 日志记录主题文件夹、配置错误与跳过原因，但不记录不必要的个人信息。
- 发生主题错误时优先保持程序和内置主题可用。

## 瘦身范围

依据《项目瘦身.md》和现有代码复核，实施时处理：

- 修正内容检查器及导入/发布脚本把实际 `assets/songs` 错写成 `assets/audios` 的问题。
- 删除已不参与判断的全屏几何字段、状态和误导性测试。
- 删除未使用的 `RefreshIconMask` 及控制器公开状态。
- 去掉对 `keypress.mp3` 的硬编码。
- 正式发布包不携带 Wallpaper Engine 的 `preview.gif`、`project.json`、开发缓存和重复产物。
- 提供空白主题模板、主题制作说明和主题验证工具。
- 保留当前 `v1.0.0` 标签和提交作为完整回滚点；主题骨架使用新分支和后续版本。

## 验证范围

自动测试覆盖配置解析、路径安全、重复 ID、损坏回退、状态保持、菜单状态、内容检查与发布排除规则。集成验证覆盖内置主题、外部测试主题、主题目录增删、手动重载、窗口/桌面模式、桌面交互、前台程序自动暂停和退出后的桌面恢复。

由于桌面 WorkerW、音频和 WebView2 属于真实 GUI 行为，自动测试通过不等于最终验收；发布前仍需在实际 Windows 桌面上手动运行新版包。

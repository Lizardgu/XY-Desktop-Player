# XY 桌面播放器 v1.0.0 设计

## 目标

把已通过桌面交互、自动播放、前台淡出暂停和退出恢复验证的项目，整理为一个可持续复用的通用桌面播放器骨架。源码仓库、程序显示名、EXE、发布目录和压缩包统一命名为“XY桌面播放器”，当前孤独摇滚素材只作为本地 v1.0.0 完整内容保留。

## 重命名范围

- 仓库目录：`outputs/XY桌面播放器`。
- 解决方案：`XYDesktopPlayer.sln`。
- 项目与命名空间：`XYDesktopPlayer.App`、`XYDesktopPlayer.Core`、`XYDesktopPlayer.Core.Tests`。
- 程序与程序集：`XYDesktopPlayer.exe`、`XYDesktopPlayer.Core.dll`。
- 产品名、窗口、托盘、错误框与退出菜单：`XY桌面播放器`。
- WebView2 虚拟域名：`xydesktop.local`。
- 完整包目录：`XY桌面播放器-v1.0.0-win-x64`。
- GitHub 源码包：`XY桌面播放器-GitHub源码-v1.0.0.zip`。
- Release 包：`XY桌面播放器-v1.0.0-win-x64.zip`。

当前网页素材中的作品标题、歌曲名和页面自身文字不做改写；它们属于内容层，不属于宿主工程名。

## GitHub 与 Release 边界

GitHub 源码包只包含标签 `v1.0.0` 的 Git 跟踪文件，不包含 `.git`、编译产物、依赖缓存、WebView2 数据、测试截图、历史发布包或导入后的音乐图片。Release 包包含自包含 win-x64 程序和当前完整素材，可供本机手动测试。

当前素材可能受第三方版权约束。生成 Release ZIP 不代表已取得公开再发布权；上传到公开 GitHub Release 前必须由使用者确认授权。源码包可以独立公开，其他用户按说明导入自己的合法素材。

## 瘦身与回滚

保留 Git 历史、素材源目录、素材 SHA-256 清单、最终完整包和两个最终 ZIP。删除内容限定为：旧发布历史、旧 ZIP、测试截图与日志、WebView2 缓存、`bin/obj`、项目级 NuGet/.NET 缓存和空验证目录。这些内容全部可由 Git、素材源和发布脚本重新生成。

删除前记录路径、文件数和字节数；删除后重新统计。最终代码提交打带注释的本地标签 `v1.0.0`。若手动测试发现问题，代码可从标签恢复，完整包可由标签源码和保留的素材源重新发布。

## 验收

- 重命名约束测试先失败，再完成重命名并转绿。
- Release 构建零警告零错误；核心、导入、发布、自检和素材清单测试通过。
- 真实验证启动自动播放、普通前台窗口 500ms 淡出暂停、回桌面立即恢复、桌面模式退出后隐藏空 WorkerW。
- 完整包根目录只有 `app`、`content`、两个启动器和说明文件。
- GitHub 源码 ZIP 解包后无忽略文件；Release ZIP 解包后逐文件路径、大小和 SHA-256 与发布目录一致。
- 最终 Git 工作区干净，标签指向最终提交，仓库不配置远程、不执行上传。

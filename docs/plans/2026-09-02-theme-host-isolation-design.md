# 主题资源地址隔离设计

## 目标

修复播放器运行期间切换主题后，歌曲与封面仍访问前一个主题资源地址的问题，同时继续采用“一个播放器、多个独立主题文件夹”的结构。

## 设计

每个主题根据其唯一 `id` 获得独立、单层的 WebView2 虚拟主机名，例如 `theme-bocchi.xydesktop.local` 和 `theme-zenless-zone-zero.xydesktop.local`。播放器发送主题数据时使用该主题映射实际生成的主机名，不再让所有主题共享固定的 `theme.xydesktop.local`。保持与已经验证可用的 `theme.xydesktop.local` 相同域名层级，避免额外子域名在 WebView2 本地媒体映射中无法进入就绪状态。

主题文件夹结构、配置格式和安装位置保持不变。内置“孤独摇滚”仍位于发布包的 `content/themes/孤独摇滚`；外部主题仍位于用户主题安装目录，每个主题占用一个独立子文件夹。

## 错误处理与验证

主题 `id` 已由加载器限制为小写字母、数字、点、横线和下划线，因此可安全转成主机标签；点和下划线统一替换为横线，避免产生额外域名层级或不兼容标签。测试必须证明两个不同主题生成不同主机名，且运行数据中的音频与封面网址使用各自对应的主机名。最后通过完整核心测试、Release 构建和真实热切换验收确认。
